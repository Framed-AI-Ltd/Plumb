# Plumb

Plumb is the Framed design system: calm, warm, and restrained. It uses Ant Design's colour system on cream neutrals with a Denim primary, flat 2.0 depth, and is always honest about what is known.

## Where to start

1. **Layouts → Guide** explains how to build a page; **Layouts → Page templates** are complete pages to start from.
2. **Components** has every generic component; **Framed** has the product patterns (estimates, proposals, records, collaboration, marketplace).
3. **Workflow** walks one project end to end: Intake, Scope & estimate, Proposal review, Property record.
4. Use the toolbar to try **Theme** (light/dark), **Neutrals**, **Inputs** (four field styles), and **Density**.

## Principles in brief

1. Restraint first: about 60-30-10, no gradients.
2. One colour, one meaning.
3. Soft depth, few lines.
4. One loud thing per region.
5. Friendly, exact type.
6. Speak like a helpful neighbour.

The truth principles still apply: unknowns stay unknown, facts show how they're known, drafts look like drafts, lifecycle is visible, private stays private, money is honest, and deliberate decisions get a pause.
