# Plumb 0.0.1

Initial public release of `@framed-ai/plumb`, Framed's contractor-first React design system.

- React Aria behavior with Denim, outlined inputs and compiled StyleX styles.
- English/French components and page patterns, with accessibility, browser and responsive visual checks.
- Partial totals are derived from unpriced estimate lines, and formatted text uses bounded forward-only parsing.
- Storybook carries the applicable font copyright/OFL notices; development matcher/glob advisories are resolved with tested compatibility exports.
- Husky staged checks, shared agent skills, Gitflow guidance, organization-member Codex reviews and GitHub Pages/npm publishing workflows.

Plumb is source-available under PolyForm Noncommercial 1.0.0. Commercial licensing contacts and the named-individual permission are documented in the licensing guide.
