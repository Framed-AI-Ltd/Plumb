# Agent quickstart

Read `AGENTS.md`, then `CONTRIBUTING.md`, then the relevant procedure in [workflow.md](workflow.md). Inspect `src/index.ts`, `docs/catalog.json` and nearby stories before adding UI.

Use an isolated worktree and a scoped branch. Never inspect secret files. Run the applicable checks and report actual rendered verification separately from static checks. Do not claim owner approval, authentication, verified signing or configured branch protection without evidence.
