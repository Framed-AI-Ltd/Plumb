---
name: frontier-review
description: Prepare an explicitly requested independent frontier-model review of a scoped Plumb change.
---

Use this procedure when a frontier or independent second review is requested. Provide the reviewer the user objective, scoped diff, relevant raw files, acceptance criteria and allowed local checks. Do not feed the desired conclusion or ask the reviewer to rubber-stamp a patch.

Use an available authorized frontier model from a different model family than the primary reviewer. Record the actual provider and model used. If unavailable, report that limitation and perform the local evidence review without claiming an independent frontier pass. Do not transmit secrets.

Reconcile disagreements against code and observable behavior, fix confirmed defects and add executable review feedback in the same PR. Retain unresolved findings and validation boundaries in the report. A second review does not authorize publication or owner visual approval.
